# 🍽️ FoodGPT

**FoodGPT** is a web-based recipe suggestion platform that helps users discover delicious recipes based on the ingredients they already have at home. Built with a user-friendly interface, the application leverages a dynamic search feature to offer relevant recipe suggestions and direct links to detailed instructions.

## 🚀 Features

- Search for recipes based on a list of ingredients.
- Dynamic display of matching recipes.
- Interactive user interface with responsive design.
- Easy navigation between homepage and recipe search page.
- Includes links to external recipe sources for more information.
